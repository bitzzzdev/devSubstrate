## Objective
I audited every shell, fish, and Python script on the `main`, `dev`, and
`smartCurlScripts` branches, fixed every real bug, and made system-changing
scripts survive a device reboot until a revert/resume script runs or the
device is reset.

## Changes
- [x] I fixed CR contamination from `adb shell` output: `pm list packages`
      lines end with CR, so anchored package greps and exact-match Fish
      string matches silently failed. Package parsing now strips CR in
      `manage-shopping-traffic.sh`, `termux-manage-shopping-traffic.sh`,
      `termux-hotspot-traffic-control.sh`, `hotspot-background-traffic-control.sh`,
      and `audit-android-storage.sh`, with the Fish equivalents.
- [x] I fixed Fish UID extraction: `string match -r` returned the whole
      `uid:NNN` match, so `netpolicy` and `iptables --uid-owner` received
      garbage. All Fish UID extractions now use `string match -rg` with
      1-based capture group indices (Fish prints only the capture groups).
- [x] I fixed the Fish bounds math in `manage-shopping-traffic.fish`
      (`automate-ui`), which read capture groups 2-5 after the `-rg` switch
      and tapped the wrong coordinates.
- [x] I fixed the Termux storage audit deleting `"$TMPDIR"/*` when TMPDIR is
      unset, which crashes bash under `set -u` and can expand to
      `rm -rf /*` in fish. Both languages now resolve a safe default, guard
      against `/` and `$HOME`, and use `find -mindepth 1 -xdev -delete`.
- [x] I hardened the `/etc/sudoers` edit in `manage-sudo-user.sh` and
      `.fish`: timestamped backup plus `visudo -cf` validation, restoring the
      backup when validation fails.
- [x] I added persistence on `dev`: Magisk/KernelSU boot hooks at
      `/data/adb/service.d/devsubstrate-shopping-restrictions.sh` and
      `/data/adb/service.d/devsubstrate-hotspot-restrictions.sh`. The hook
      re-applies AppOps modes, standby bucket, NetPolicy blacklist, and
      iptables/ip6tables DROP rules at every boot, re-resolving per-package
      UIDs via `cmd package list packages -U`. Installed on `pause`/`apply`,
      removed on `resume`/`revert`. A factory reset wipes `/data` and the
      hook with it.
- [x] I guarded every `install_boot_hook` call site with `|| true` (bash) or
      `; or true` (fish) so a failed hook install cannot abort pause/apply
      under `set -e`.
- [x] I fixed the `smartCurlScripts` CI grep checks to match the `SOURCE_REF`
      variable the launchers actually use, and added `.gitignore` entries for
      `scripts/__pycache__/` on `dev` and `main`.

## Notes
- `main` carries no boot hook by design: its scripts never apply iptables,
  and AppOps, NetPolicy, standby buckets, and `settings global` persist
  natively under `/data` on non-rooted devices.
- Termux scripts need no hook: they never touch iptables.
- I could not exercise the boot hook end to end because no rooted Android
  device or emulator was available in this environment. The hook logic was
  verified by syntax checks, `sh -n` on the generated body, and code review
  of the install/remove paths.
