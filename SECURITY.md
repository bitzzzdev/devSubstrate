# Security Policy

## Supported Scope

DevSubstrate documents systems administration workflows, hardware fixes, and third-party API integration patterns. Security reports regarding published scripts, credentials exposure, or automated workflows are reviewed promptly.

## Reporting a Vulnerability

If you discover a security flaw, credential leak, or harmful script pattern within this repository:

1. Do not open a public GitHub issue.
2. Email details of the vulnerability directly to:
   `bitzzdev@gmail.com`
3. Include:
   - File path and affected lines
   - Description of the security risk or vulnerability
   - Recommended remediation or replacement command

You will receive an acknowledgment within 48 hours, followed by a patch or corrective commit once verified.
