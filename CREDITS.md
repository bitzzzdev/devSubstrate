# Third-Party Credits and Attribution

The `devSubstrate` project references, integrates with, and provides automation for the following open-source utilities, operating system interfaces, and developer platforms.

## 1. Operating System Subsystems and Toolchains

### Android Open Source Project (AOSP)
- **Components**: Android Debug Bridge (`adb`), Application Operations (`cmd appops`), Network Policy Manager (`cmd netpolicy`), UIAutomator, Accessibility Framework (`AccessibilityService`).
- **License**: Apache License, Version 2.0
- **Source**: https://android.googlesource.com/

### Linux Kernel Netfilter / iptables
- **Components**: `iptables`, `ip6tables`, Netfilter packet filtering subsystem.
- **License**: GNU General Public License, Version 2.0 (GPL-2.0)
- **Source**: https://www.netfilter.org/

### Termux
- **Components**: Android terminal emulator, package environment, and Linux userland on Android.
- **License**: GNU General Public License, Version 3.0 (GPL-3.0)
- **Source**: https://github.com/termux/termux-app

### MPV Player
- **Components**: Command-line media player and video streaming client configuration profiles.
- **License**: GNU General Public License, Version 2.0 or later (GPL-2.0-or-later) / LGPL-2.1-or-later
- **Source**: https://github.com/mpv-player/mpv

### Python

- **License**: Python Software Foundation (PSF) License Agreement
- **Source**: https://www.python.org/
