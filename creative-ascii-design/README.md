## 1. React Bits (reactbits.dev)

A curated collection of animated, interactive React components with a focus on creative web design, micro-interactions, and visual polish.

### Highlights
- Animated text components, magnetic buttons, and cursor effects.
- Direct drop-in code snippets compatible with React, Next.js, and Tailwind CSS.
- Zero extra heavy dependencies for individual components.

---

## 2. Efecto (efecto.app)

An AI-native collaborative canvas founded by Pablo Stanley. It bridges visual design and code generation for developers and designers.

### Features
- Real-time layout canvas with auto-layout and responsive breakpoints.
- AI assistant integration via Model Context Protocol (MCP) and custom skills.
- Export directly to clean React, Tailwind CSS, or WebGL shader backgrounds.

---

## 3. ascii.rest

A lightweight, zero-dependency TypeScript library with interactive ASCII art elements designed for modern web applications.

### Use Cases
- Retro CLI aesthetic landing pages.
- Lightweight animated loaders, 3D rotating text wireframes, and ASCII data charts.
- Works across React, Astro, Vue, and vanilla JavaScript.

---

## 4. ASCII Magic (ascii-magic.com)

A browser studio that converts standard raster media (images and video) into ASCII text art, dithering textures, and retro graphics.

### Practical Applications
- Exporting monochrome or colored character art for terminal banners and CLI welcome screens.
- Generating retro poster assets for web hero sections.
- Real-time webcam or video stream ASCII filters.

---

## 5. Asciify Engine (asciify.org)

An open-source, framework-agnostic rendering engine for text graphics and character-based canvas animation.

### Key Capabilities
- Transforms live images, video feeds, and GIFs into character matrices.
- Supports custom glyph sets, threshold mapping, and contrast curves.
- Ideal for creative coding experiments and retro interactive web experiences.

---

## 6. Asciicore Figma Plugin (vga asciicore.exe)

A popular Figma community plugin used by interface designers to generate VGA, dither, and ASCII glitch art directly on canvas artboards.

### Workflow
1. Select any raster image, icon, or frame inside Figma.
2. Launch `vga asciicore.exe` from the plugins menu.
3. Adjust character density, font family, color channels, and dithering matrix.
4. Insert the generated text or vector object back into your layout.
